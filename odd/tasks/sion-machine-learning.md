## Objective

Build a static, interactive 24-day Machine Learning site named **Sion Machine Learning**, inspired by `https://advientoml2026.netlify.app/` but reimplemented with SION's institutional identity and with our AI4I predictive-maintenance project as the running example. Every lab, metric, dataset sample and result must come from our real pipeline, not from invented numbers or verbatim copies of the reference source.

## Specs

- **S1 — Brand**: the visible site name is exactly `Sion Machine Learning`. The word `Adviento`/`Aviento` must not appear in the brand or navigation. The framing is a SION-X portfolio/demo piece: `24 laboratorios de mantenimiento predictivo sobre AI4I`.
- **S2 — Calendar**: 24 days grouped in 4 weeks, in the approved mapping to AI4I. All days are open from the start; no December date lock. Progress, filters and completion state are retained. User decision: `Todos abiertos`.
- **S3 — Day contract**: each day exposes topic, title, subtitle, concept summary, key takeaway, Python snippet, one interactive lab, one multiple-choice quiz with explanation, one challenge, and (where available) links to our notebook on GitHub and Google Colab.
- **S4 — Language**: visible copy is Spanish (es-AR); code identifiers, types, comments, tests and technical file names are English. The site interface and educational copy follow the reference's Spanish register without copying its sentences.
- **S5 — Stack**: React 19 + Vite + TypeScript + Tailwind 4, static SPA under `web/`. No backend required. State lives in `localStorage` (`sion_ml_progress_v1`), with JSON export, reset, `?dia=N` deep links, responsive layout and `prefers-reduced-motion` support. User decision: `React + Vite + Tailwind`.
- **S6 — Identity**: SION institutional visual identity — background `#05080D`, primary `#00D1B2`, deep teal `#00766B`, text `#E6F1F0`, surfaces `#0B1118`/`#101A22`, Inter for UI and Outfit for display. No copied winter imagery, no Netlify/HUD assets from the reference. Contrast must meet WCAG AA for body text and controls. User decision: `SION institucional`.
- **S7 — Real data**: every displayed metric comes from this repository's AI4I pipeline: 10,000 rows, 3.4% failures, 2,000 test rows / 68 failures, F1 table `0.1772 / 0.6286 / 0.3095 / 0.7581`, tuned Decision Tree `max_depth=8`, `min_samples_leaf=3`, CV F1 `0.7096 ± 0.0436`, 21 missed failures. Lab data is generated by `scripts/export_web_data.py` from `data/raw/ai4i2020.csv` into `web/src/data/ai4i.json`; no invented distributions or scores.
- **S8 — Labs**: reimplement the 24 reference lab mechanics with our own code and visuals, adapted to AI4I: `pandas-inspector`, `nulls-imputation`, `feature-engineering`, `categorical-encoding`, `feature-scaling`, `train-test-leakage`, `linear-regression-fit`, `regression-metrics`, `target-diagnostics`, `logistic-sigmoid`, `confusion-matrix`, `imbalanced-metrics`, `knn-canvas`, `knn-scaling`, `decision-tree-depth`, `random-forest-ensemble`, `kmeans-stepper`, `kmeans-real`, `pre-entrega-checklist`, `sklearn-pipeline`, `gridsearch-heatmap`, `joblib-serialization`, `model-comparison`, `final-project`. The unlicensed reference repository is a functional reference only; no verbatim source, strings or assets are copied.
- **S9 — Quality**: `npm run test` and `npm run build` pass from `web/`; unit tests cover progress sanitization, content invariants (24 unique days, valid quiz indices, lab ids, notebook URLs), and lab math (metrics, sigmoid, split, regression, KNN, clustering helpers). No console errors, no broken links, keyboard-operable controls, labelled form inputs.
- **S10 — Notebook links**: each day links to our generated notebooks in `miguelpuente/agri-machinery-failure-prediction` (GitHub and Colab), never to the VintaBytes course notebooks.
- **Assumption A1**: the site lives inside this repository under `web/` and deploys as a static build with a relative base, so it can be served by Netlify or SION infrastructure later without code changes. Deployment itself requires explicit authorization.

El problema

  • La teoría ocupa la cursada; el pipeline completo aparece recién en el proyecto final.
  • Los datasets de juguete no enseñan desbalance, leakage, tuning ni límites.
  • El portfolio de egreso muestra materias, pero no evidencia de haber entrenado y evaluado.

La propuesta

24 sesiones de 20–30 minutos, cuatro semanas, un caso real: carga, limpieza, features, encoding, escalado, split, regresión, clasificación, métricas, KNN, árboles, Random Forest, clustering, pipelines, GridSearchCV, joblib y proyecto final.

  • Concepto corto + código + laboratorio interactivo + quiz + reto + notebook.
  • Funciona en celular, como PWA, en español, sin backend ni datos de estudiantes.
  • Glosario, material teórico en PDF y certificado de recorrido.

KPIs del piloto

Completion ≥ 70 % Mejora de quizzes ≥ 20 % Proyecto ≥ 70 % rúbrica Satisfacción ≥ 80 % Horas docentes ahorradas

Metas propuestas para el piloto, no garantías.

Modelo de adopción

Piloto → licencia institucional/white-label → co-creación de contenido e integración con LMS. Sin costo por asiento; hosting estático y repositorio público adaptable.

El pedido

“Probemos un módulo con una cohorte. Si los indicadores se cumplen, escalamos; si no, ajustamos sin haber comprado una plataforma.”

Riesgos y mitigación
